# Coding Standards (Guide)

Canonical rules: [docs/architecture/09_Coding_Standards.md](../architecture/09_Coding_Standards.md)

## 60-second checklist

- Constructor injection
- Domain exceptions + global handler
- `@Transactional` on writes
- DTOs out, entities in
- `@PreAuthorize` on APIs
- No feature→feature imports
- Tests: happy + negative
